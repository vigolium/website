# Vigolium Landing Page Designs

| Route | Theme | Description |
|-------|-------|-------------|
| `/1` | **Noir Blueprint** | Midnight navy with cyan-white technical drawings. Blueprint grids, dimension lines, crosshair cursors, annotation callouts. |
| `/2` | **Glitch Matrix** | Terminal green on black. Falling code rain, monospace everything, command-line aesthetics, matrix-style digital corruption. |
| `/3` | **Twilight Console** | Soft dark with muted lavender, sage green, and peach. Gentle IDE/dashboard aesthetic — syntax-highlighted blocks, soft panels, muted status pills. |
| `/5` | **Terminal Brutalist** | Dark, monospace-heavy layout with minimal decoration. Raw typography hierarchy on near-black background with thin border separators and a single muted accent on the CTA. |
| `/6` | **Dark Editorial** | Deep dark-green/charcoal background with elegant serif headings and clean sans-serif body. Centered, spacious layout with subtle ASCII texture and a warm-orange CTA accent. |
| `/7` | **Polished Dev Dark** | Refined dark page with soft blue-gray palette, clean sans-serif typography, and generous whitespace. Text-centered hero with blue CTA and three-column features. |
| `/8` | **Noir Grid** | Pitch-black background with visible dot-grid overlay. Geometric sans-serif typography, rigid column-snapped layout, with neon cyan used sparingly for links only. |
| `/9` | **Midnight Glassmorphism** | Dark indigo-to-black gradient with frosted-glass card surfaces and semi-transparent borders. Bold sans-serif headings with soft purple-violet glow accents. |
| `/10` | **Console Minimal** | Everything rendered terminal-style — monospace throughout, green-on-black text, cursor-blink animations, command-line section headers. No images, no cards, just text. |
| `/11` | **Dark Slab** | Warm charcoal background with thick slab-serif headings and compact sans-serif body. Sections divided by bold horizontal bands with a rust orange CTA accent. |
| `/12` | **Obsidian Mono** | Pure black with high-contrast white text, hairline borders, and deliberate negative space. Condensed grotesque headlines, monospace labels. Zero color except electric blue. |
| `/13` | **Void Gradient** | Subtle dark gradient from deep navy to true black with airy layout and thin-weight sans-serif typography. Floating sections with muted teal accents — minimal and quiet. |
